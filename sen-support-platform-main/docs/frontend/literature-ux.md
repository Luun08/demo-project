# Литература: UX, доступность, юзабилити

Список пока неполный. Научные статьи за последние пять лет добавим отдельно (задача SSP-31).

1. W3C. *Web Content Accessibility Guidelines (WCAG) 2.1*. W3C Recommendation, 2018. https://www.w3.org/TR/WCAG21/
   Основной стандарт доступности. Используем критерии контраста, размера целей, подписей к полям и текстовых альтернатив для требований FE-NFR-01 и FE-FR-07.

2. Brooke J. *SUS: A «quick and dirty» usability scale* // Usability Evaluation in Industry. London: Taylor & Francis, 1996. С. 189-194.
   Шкала SUS из 10 вопросов; порог 68 баллов принят как средний уровень. Используем в плане юзабилити-тестирования (FE-NFR-08).

3. ISO 9241-11:2018. *Ergonomics of human-system interaction - Part 11: Usability: Definitions and concepts*.
   Определение юзабилити через результативность, эффективность и удовлетворённость. На этом строим метрики теста: доля выполненных задач, время, оценка SUS.

4. Nielsen J. *10 Usability Heuristics for User Interface Design*. Nielsen Norman Group. https://www.nngroup.com/articles/ten-usability-heuristics/
   Эвристики для проверки макетов и прототипа: видимость состояния системы, предотвращение ошибок, понятный язык.
