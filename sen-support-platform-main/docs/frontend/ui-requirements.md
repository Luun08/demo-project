# Требования к интерфейсу

Приоритеты: **M**: обязательно, **S**: желательно, **C**: если успеем.
Источники: «Опрос №N» - номер вывода в `docs/research/evidence-to-requirements.md`; SEC, PRV, AUD: номера требований по безопасности и приватности из документов команды.
Столбец «Прототип» показывает состояние демо-версии в `/frontend`: да / частично / нет.

## Функциональные

| ID | Требование | Прио. | Критерий приёмки | Источник | Прототип |
|---|---|---|---|---|---|
| FE-FR-01 | Регистрация и вход с выбором роли (родитель / специалист) | M | Регистрация за ≤ 2 минут; ошибки валидации видны рядом с полем | Требования безопасности команды (`docs/security-privacy-requirements.md`) | частично (вход демонстрационный) |
| FE-FR-02 | Кабинет родителя: быстрый доступ к дневнику и расписанию с главной | M | С главной до записи в дневник ≤ 3 клика | Опрос №1 | да |
| FE-FR-03 | Профиль ребёнка с явным согласием на обработку данных, минимум полей | M | Без отметки согласия профиль не сохраняется; согласие можно отозвать; диагнозы не запрашиваются | PRV-07, Опрос №15 | да |
| FE-FR-04 | Расписание занятий: список и календарь, статус, добавление | M | Занятие добавляется за ≤ 4 поля; отображается в списке и календаре | Опрос №1 | да |
| FE-FR-05 | Запись в дневник: наблюдение, прогресс, рекомендация, цель, вложение | M | Запись сохраняется за ≤ 3 шага; можно приложить файл | Опрос №9, №10, №16 | частично (кнопка вложения без загрузки) |
| FE-FR-06 | Переключатель видимости записи shared / specialists_only | M | Режим виден значком и подписью на каждой записи; родитель не видит записи «только специалисты» | Опрос №3, №5 | да |
| FE-FR-07 | График прогресса с таблицей-альтернативой | S | Есть таблица для скринридера; переключение график/таблица | WCAG 1.1.1 | да |
| FE-FR-08 | Экран «Кто смотрел данные ребёнка» | M | Список «кто, когда, что»; фильтр по периоду; попытки без доступа выделены | AUD-04, Опрос №4 | да |
| FE-FR-09 | Кабинет специалиста: только назначенные дети, расписание, наблюдения | M | Специалист видит только детей, к которым допущен | RBAC | частично (один ребёнок в демо) |
| FE-FR-10 | Админ-панель: пользователи, подтверждение специалистов, блокировка | M | Администратор не видит содержимое дневников | SEC-15 | да |
| FE-FR-11 | Переключение языка kk / ru (в демо также en) | M | Все основные экраны переведены; выбор сохраняется | Опрос №8 | да |
| FE-FR-12 | Напоминания о занятиях без имени ребёнка | C | Текст уведомления не содержит имени ребёнка | PRV, утечки | да |
| FE-FR-13 | Список «Рекомендации для дома» в кабинете родителя | S | Рекомендации специалистов собраны отдельно; родитель находит последнюю за ≤ 2 клика | Опрос №2 | частично (есть тип «Рекомендация», отдельного списка нет) |
| FE-FR-14 | Шаблоны записей для специалиста | C | Выбор шаблона заполняет тип и заголовок записи | Опрос №12 | нет |
| FE-FR-15 | Короткий отчёт родителю в пару кликов | C | Отправка отчёта не более чем за 2 действия после записи | Опрос №13 | нет |
| FE-FR-16 | Категории и фильтры записей в дневнике | S | Записи фильтруются по типу | Опрос №14 | нет |
