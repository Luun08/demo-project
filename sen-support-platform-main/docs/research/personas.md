# Персоны и сценарии

Персоны собраны по ответам анонимного опроса (родители n = 3, специалисты n = 4, 22-23.10.2026, см. `evidence-to-requirements.md`). Это обобщённые образы, а не реальные люди. Имён и возраста у них нет, потому что в опросе мы это не спрашивали. Персоны отражают только предварительные выводы небольшого опроса; уточнять их следует по результатам последующей оценки сценариев.

## Родитель
- **Что хочет:** держать расписание, рекомендации и записи о развитии ребёнка в одном месте.
- **Что мешает (по опросу):** расписание и общение со специалистами живут в мессенджерах (3 из 3). Домашние задания и рекомендации теряются (3 из 3). Записи о развитии ведёт только один из трёх.
- **Устройство:** смартфон (3 из 3), ноутбук редко. Нужен переключатель русского и казахского.
- **Главные задачи:** посмотреть ближайшее занятие, найти рекомендации для дома, решить, кто видит запись, проверить, кто смотрел данные ребёнка.
- **Приватность:** боится утечек (3 из 3) и того, что запись увидит посторонний (2 из 3). Журнал «кто смотрел данные» все трое оценили на 5 из 5.

## Специалист (логопед, педагог, тьютор)
- **Что хочет:** быстро записать наблюдения после занятия и передать рекомендации родителям.
- **Что мешает (по опросу):** записи ведутся в Excel и Word (по 3 из 4), информация уходит через WhatsApp и Telegram (4 из 4). Теряется динамика прогресса и домашние рекомендации. Неудобно раскладывать прогресс по целям.
- **Устройство:** смартфон (4 из 4), ноутбук (3 из 4).
- **Главные задачи:** добавить занятие, записать наблюдение за 2-3 минуты, отметить рекомендации для дома, отправить родителю короткий отчёт.
- **Приватность:** часть заметок не должна попадать к родителям (2 из 4). Подробные диагнозы не нужны. Утечек и доступа посторонних боятся все четверо.

## Администратор (координатор центра)
- **Что хочет:** управлять пользователями и подтверждать специалистов.
- **Задачи:** одобрить специалиста, заблокировать аккаунт, найти пользователя.
- **Приватность:** содержимое дневников не видит.
- **Важно:** администраторов в опросе не было. Эта персона построена по ролям проекта, поэтому считается предположением.

## Сценарии (user flows)

| № | Роль | Сценарий | Шаги |
|---|---|---|---|
| 1 | Родитель | Регистрация и профиль ребёнка | Главная → Регистрация (роль «родитель») → Профиль ребёнка → отметить согласие → Сохранить |
| 2 | Родитель | Добавить занятие | Расписание → Добавить занятие → заполнить поля → Добавить |
| 3 | Родитель | Запись в дневник с видимостью | Дневник → Новая запись → тип и текст → переключатель «Только специалисты» → Сохранить |
| 4 | Родитель | Проверить, кто смотрел данные | Журнал доступа → период → Применить → смотрим строки, в том числе попытки без доступа |
| 5 | Специалист | Запись наблюдения после занятия | Вход → Команда или Дневник → Новая запись → Сохранить |
| 6 | Администратор | Подтвердить специалиста | Вход → Панель администратора → найти пользователя → Подтвердить |
